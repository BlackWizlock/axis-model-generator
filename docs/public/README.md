# Axis Model Generator

Проект [Axis Consult](https://axisconsult.ru) и [Axis Platform](https://axisplatform.ru)
для автоматизации подготовки моделей зданий для Москвы и Московской области.
Цель продукта: получать низкополигональную модель (НПМ), высокополигональную
модель (ВПМ) и информационную модель в формате IFC.

Проект должен уменьшить ручную подготовку и передачу файлов, выявлять ошибки
исходника до выпуска и сохранять проверяемые сведения о происхождении данных
и ограничениях обработки. Генерация этих результатов пока не реализована.

## Текущая поставка

Реализованы диагностический интерфейс командной строки (CLI) на Python,
чтение экспериментального переносимого пакета, синтетические тесты и
экспорт проверенного снимка исходников. Веб-сервис и Revit-плагин находятся
в планах; доступного сайта, скачивания плагина и установщиков пока нет.

Режим ZIP/FBX читает binary FBX 7400 и проверяет безопасность архива,
бинарную структуру, индексы геометрии, число треугольников и метаданные
встроенных PNG. Пиксели PNG не декодируются.

Режим пакета читает экспериментальную схему v1.0: хеши ресурсов, точные
массивы геометрии, связи сцены и преобразования координат. Неподдерживаемые
данные и неполные возможности отмечаются в отчёте. Ресурсы за пределами
архива не открываются. Достоверность извлечения данных из Revit не проверена.

Экспортёр читает только явно перечисленные файлы выбранного Git-коммита,
создаёт каталог, ZIP и манифест SHA-256. Приватная история Git, авторские
метаданные старой истории и пользовательские модели в снимок не входят.

## Запланированный маршрут

Планируется общедоступный сайт; загруженные пользователями модели останутся
приватными. Плагин установленного Windows Revit будет создавать переносимый
пакет. Пользователи Windows и macOS будут загружать подготовленный пакет
через браузер. Blender будет работать на сервере, установка Blender
пользователем не потребуется. Autodesk APS и 3ds Max не нужны.

Сервер без установленного Revit не читает произвольный исходный RVT.
Целевая матрица Revit 2020–2026 требует реальных испытаний и пока не является
подтверждённой поддержкой. Авторизация, задания обработки, просмотр модели,
генерация НПМ/ВПМ/IFC и поставка плагина ещё не реализованы.

## Локальный запуск

Нужен Python 3.14 или новее. Команды выполняются из каталога исходников;
`example.zip` и `example-package.zip` обозначают ваши входные архивы.

```sh
PYTHONPATH=src python3 -m model_generator example.zip --output report.json
PYTHONPATH=src python3 -m model_generator example-package.zip --kind package --output package-report.json
```

Для PowerShell сначала задайте путь к модулям:

```powershell
$env:PYTHONPATH="src"
python -m model_generator example.zip --output report.json
python -m model_generator example-package.zip --kind package --output package-report.json
```

Локальные проверки выполнены на macOS. Работоспособность на Windows и
реальные испытания Windows/Revit пока не подтверждены.

Код выхода 0 означает отсутствие отказов реализованных проверок; 1 означает
диагностический отказ; 2 означает ошибку команды или файловой операции.
Предупреждения и непроверенные правила сохраняются даже при коде 0.
Код 0 не доказывает полноту комплекта или одобрение ведомства.

## Проверки

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Включённые образцы создаются программно и содержат синтетические данные.
Клиентских моделей и приватных интеграционных образцов в снимке нет.
Проверки репозитория сверяют полную лицензию, состав экспорта, ссылки,
автономный запуск CLI и повторный экспорт из нового Git-репозитория.

## Ограничения

Профиль `technical-research-v1` имеет `status=research`,
`applicability=not_checked` и `normative_readiness=false`. Численные пороги
служат публичным техническим примером и не являются опубликованной
нормативной базой. Профиль переносимого пакета также сохраняет
`normative_readiness=false`.

Отчёт разделяет четыре независимые оси: техническую целостность
(`technical`), требования профиля (`profile`), полноту процедуры
(`procedure`) и внешние действия (`external`). Успех одной оси не
подтверждает остальные.

Сохранение силуэта, самопересечения, нормали, поля UV, семантика материалов,
достоверность извлечения из Revit, соответствие IFC/IDS, применимость
региональных требований и согласование ведомства остаются непроверенными.
Подтверждённого регионального профиля подачи нет.

## Воспроизведение публичного снимка

Явный список исходников и экспортных путей хранится в
`public/export-allowlist.json`. Для повторного экспорта автономного снимка
инициализируйте его как новый Git-репозиторий и зафиксируйте проверенные
исходники. Укажите существующий коммит и ещё не занятый каталог результата:

```sh
python3 scripts/export-public.py --revision HEAD --output _output/source-snapshot
```

Результат: каталог `_output/source-snapshot`, `public-manifest.json`
с SHA-256 каждого файла и соседний `_output/source-snapshot.zip`.
Результаты держите вне Git. Экспортёр проверяет пути и содержимое,
не копирует Git-объекты и журналы истории.

При частном использовании можно передать через `--private-policy` локальный
JSON-файл с `schema_version: 1` и `denyTokens: ["DummyCustomer"]`.
Файл политики внутри репозитория должен быть исключён из Git. Политика
проверяется локально и никогда не экспортируется. Снимок не даёт права
публиковать клиентские входы, результаты, секреты или конфигурацию окружения.
