# Axis Model Generator

Открытая разработка продукта [Axis Consult](https://axisconsult.ru) и [Axis Platform](https://axisplatform.ru) для проверки BIM-моделей и подготовки НПМ, ВПМ и IFC.

Первая поставка диагностического ядра и подробная документация находятся в [ветке codex/public-core](https://github.com/BlackWizlock/axis-model-generator/tree/codex/public-core). До слияния PR используйте эту ветку для запуска и проверок. Веб-сервис, генерация и Revit-плагин ещё разрабатываются.

Собственный код лицензируется [Apache-2.0](LICENSE). Сторонние компоненты сохраняют собственные лицензии.
